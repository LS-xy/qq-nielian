# QQ捏脸

> 把任意图片变成一张会弹的脸：涂一涂，按住往外拉，松手——「啪」。

一个纯前端的小玩具。上传图片 → 涂抹想变软的部位 → 拖拽玩耍。不依赖任何游戏引擎，变形由 WebGL 顶点着色器实时绘制。

- 在线体验：<https://imxy.cn/game/nn/>
- 作品墙：<https://imxy.cn/game/nn/gallery.php>
- 作者：**LSMa**

---

## 玩法

1. **导入**：点加号选图，或直接把图片拖进页面、`Ctrl+V` 粘贴，也可以先用自带的示例脸蛋
2. **涂抹**：列表里选画笔，把想让它变软的地方涂一遍；涂错了用橡皮擦，也可以「全部清除」或「全部软糯」
3. **开玩**：按住脸蛋往外拉，松手就是「啪」的一下回弹；满意了可以保存分享或下载图片

侧边栏里还有：大家做的脸蛋、下载源码、查看简介、贡献入口。

---

## 特性

- **皮肤式拉扯**：位移用 `tanh` 做饱和，一开始跟手，越拉越费劲，最后扯不动；松手才回弹
- **无边界过渡**：影响范围用高斯衰减 `exp(-d²/scale²)`，看不到任何圆形硬边
- **涂抹决定软硬**：每个顶点带一个 0~1 的权重，没涂到的地方保持不动
- **只画涂过的地方**：白色蒙版盖在未涂抹区域，边缘有一圈很淡的阴影
- **移动端适配**：双指缩放与平移，`touch-action: none` 防误触
- **图片清晰**：纹理缩放成 2 的幂并生成 mipmap，大图缩小也不糊
- **一键分享**：分享链接形如 `?img=<图片地址>`，点开直接进入涂抹步骤
- **三套主题无关的简约粉白视觉**，无外部依赖、无构建步骤

## 部署

**环境要求**：PHP 5.6+（推荐 7.4 / 8.x），需要 `ZipArchive` 扩展（仅「下载源码」功能用到），浏览器需支持 WebGL。

1. 把全部文件上传到站点任意目录，例如 `https://your.site/game/nn/`
2. 确保 `save/` 目录存在且可写（`chmod 755` 通常够；没有的话程序会自动尝试创建）
3. 直接访问 `index.php` 即可，无需数据库、无需安装向导

### 配置

编辑 `config.php`：

```php
return [
    'author'     => 'LSMa',
    'title'      => 'QQ捏脸',
    'contribute' => 'https://github.com/LS-xy/qq-nielian',
    'repo'       => 'https://github.com/LS-xy/qq-nielian',
];
```

| 键 | 作用 |
|---|---|
| `author` | 显示在侧边栏底部与简介面板 |
| `contribute` | 侧边栏「贡献」按钮的跳转地址 |
| `repo` | 简介面板里展示的源码地址 |

### 纯静态托管

如果放在 GitHub Pages / Vercel 这类不支持 PHP 的环境：

- 保留 `index.php` 与 `app.js`，把 `index.php` 改名为 `index.html` 并删掉其中的 PHP 片段
- 去掉「保存分享」「下载源码」「大家做的脸蛋」三个入口
- 其余（导入、涂抹、开玩、下载图片）全部是纯前端实现，可以正常工作

## 实现原理

### 网格

图片被铺成 `N × N`（默认 84）的三角网格。每个顶点保存三组数据：

- `rx, ry`：静止位置
- `px, py`：当前位置
- `wt`：柔软权重（0 = 硬，1 = 最软）

### 弹簧

每个顶点是一个阻尼弹簧，回弹时求解：

```
a = (r - p) * k * w - v * damp
v += a
p += v
```

拖动期间**冻结物理**（只跟手、速度清零），松手后才开启回弹，所以按住不放时是静态形变，不会边拖边荡。

### 拉扯

拖动时以手指按下点为原点，计算总位移后做 `tanh` 饱和：

```js
eff = limit * Math.tanh(len / (limit * 0.82))
```

再用高斯衰减把位移分配到周围的顶点上，因此范围随拉力缓慢扩大，且没有可见边界。

### 渲染

顶点位置每帧写入 `Float32Array` 后上传给 GPU，由顶点着色器做 `[-1,1]` 映射，片元着色器负责图片采样与白色蒙版混色。整个动画不经过 Canvas 2D。

### 涂抹

笔刷把半径内的顶点权重抬到 1，过渡带用 `smoothstep`；橡皮擦反向压权重，归零时顺手把顶点复位。抬手后对权重做两遍邻域平滑，涂抹出来的边界不会有锯齿。
